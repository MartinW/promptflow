Langfuse is the storage layer. PromptFlow is the editor.

Built for teams who need a better authoring experience without leaving the Langfuse ecosystem.

Why PromptFlow?

Langfuse is powerful, but its default prompt UI wasn't built for rapid authoring.

Pain: No Tag Navigation

Langfuse prompts support tags, but there's no built-in filtering or tag-first organization. Finding prompts by purpose or consumer app is manual.

Pain: No Integrated Playground

Testing prompt changes means copying templates into a separate tool or writing code. No live preview with token counts and streaming.

What You Get

Authoring UI

Compose editor with optional System Prompt and User Context fields. Inline diff viewer for version comparisons. Drafts by default — explicit "Promote to production" control.

Integrated Playground

Stream responses via OpenRouter or Vercel AI Gateway. Live token counts, cost estimation, and latency. Provider-grouped model picker. Test before you save.

Tag-First Organization

Filter prompts by purpose (voice:*, image:*, eval:*), consumer app (app:*), or locale (lang:*). Tag conventions documented in @promptflow/core.

One Registry, Multiple Consumers

PromptFlow is more than a web app — it's an ecosystem for managing prompts across platforms.

Web

Next.js authoring UI with integrated playground. The primary interface for prompt management.

CLI

@promptflow/cli — list, get, pull, push, run, and diff prompts from the terminal. Author prompts as JSON files.

MCP Server

Register with Claude Desktop or Cursor. Your Langfuse prompts become MCP Prompts and tools.

Cadence iOS

Reads voice:* tagged prompts aloud via OpenRouter. Remote prompt management — edit in the web UI, see changes on launch.

Use with AI Agents

Your Langfuse prompts become first-class MCP Prompts that host LLMs can invoke by name.

MCP Server

Register @promptflow/mcp-server with Claude Desktop, Cursor, or other MCP clients. Your prompts become invocable with version pinning, auto-discovered arguments, and built-in search tools.

Claude Desktop

{
  "mcpServers": {
    "promptflow": {
      "command": "npx",
      "args": ["-y", "@promptflow/mcp-server"],
      "env": {
        "LANGFUSE_PUBLIC_KEY": "pk-lf-...",
        "LANGFUSE_SECRET_KEY": "sk-lf-...",
        "LANGFUSE_HOST": "https://cloud.langfuse.com"
      }
    }
  }
}

Config path: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS)

Tag Conventions

PromptFlow layers conventions on Langfuse's plain-string tags. Consumers filter by namespace.

Namespace Purpose Example
voice: TTS-optimized templates voice:greeting
image: Image-generation templates image:product-shot
eval: LLM-as-judge templates eval:helpfulness
app: Scope to a consumer app app:cadence:greeting
lang: Locale lang:en-GB
